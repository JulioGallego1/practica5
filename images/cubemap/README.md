# SkyboxKit Cubemap

This package contains six 1024 x 1024 PNG cubemap faces:

- front.png
- back.png
- left.png
- right.png
- up.png
- down.png

The images are intended to be viewed from inside the cube.

## Roblox filename mapping

| Cubemap face | Roblox skybox property |
| --- | --- |
| front.png | SkyboxFt |
| back.png | SkyboxBk |
| left.png | SkyboxLf |
| right.png | SkyboxRt |
| up.png | SkyboxUp |
| down.png | SkyboxDn |

Extract the ZIP, upload the six PNG files, and assign each image to the matching property in your target engine.
